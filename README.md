# NopOS

NopOS is a small experimental operating system and testbed for the [AstraC](https://github.com/Antonako1/AstraC) compiler and assembler.

It targets old x86 hardware and is primarily developed and tested around a:

* **CPU:** Intel Pentium 4, 2 GHz
* **Architecture:** i386 / x86 32-bit
* **RAM:** 1 GB DDR1

## Purpose

Provides a simple environment for testing:

* AstraC compiler
* AstraC assembler
